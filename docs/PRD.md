#  循环小岛 --(**Loop Island**)

> 按照用户需要的时间规定一个周期，并有计划地循环执行这个周期的任务，同时带有 TodoList 的基本功能。
> 定位：无登录 · 本地存储 · 普通 TodoList · N 天循环计划 · 导入导出恢复 · 轻量统计。

## 一、核心概念

- **普通任务**：一次性任务，可设置今天、明天、自定义日期或无日期。
- **循环计划**：以 N 天为一个周期，每天可安排不同任务，例如 8 天跑步训练。
- **周期模板**：第 1 天到第 N 天的任务定义。
- **任务实例**：某一天实际出现的任务。勾选完成只影响当天实例，不修改模板。
- **任务记录**：记录任务实例的状态变化，包括完成、未完成、跳过、未完成原因、完成时间等。
- **循环结束日期**：循环计划可以设置最终结束时间，例如 8 天跑步计划到 2026-10-19 结束。结束日期当天仍然执行，次日不再生成新任务实例。
- **本地数据**：所有数据只保存在本机，不上传云端。
- **无登录**：打开即用，不注册、不登录、不绑定账号。

## 二、功能清单

### 1. 普通 TodoList

- 添加任务
- 编辑任务：标题、备注、日期、提醒时间
- 删除任务
- 勾选完成 / 取消完成
- 标记未完成 / 跳过
- 日期类型：今天、明天、自定义日期、无日期
- 分组查看：今天、明天、未安排、已完成
- 点击任务进入详情编辑
- 任务详情中可查看历史记录

### 2. 循环计划

- 新建循环计划：名称、周期天数 N、起始日
- 编辑第 1 天到第 N 天的任务
- 每天可以放多个任务，也可以为空
- 按 N 天自动循环
- 今日显示：当前是第几天 / 共 N 天
- 明日预览：明天是第几天，要做什么
- 勾选完成当天任务
- 暂停 / 启用 / 编辑 / 删除循环计划
- 修改循环任务时，简化成两个选项：
  - 仅本次
  - 以后所有

- 【新增】设置循环结束方式：
  - 永不结束
  - 循环 X 次后结束
  - 到指定日期结束
- 【新增】计划列表显示结束日期和剩余轮数
- 【新增】已结束计划自动归档

### 3. 今日 / 明日

- 今日页汇总：
  - 普通任务中日期是今天的
  - 所有启用循环计划中今天对应的任务
- 明日预览：
  - 普通任务中日期是明天的
  - 循环计划中明天对应的任务
- 可以直接在今日页勾选完成
- 可以快速添加普通任务
- 今日任务未完成时，可以追加说明原因

### 4. 本地提醒

- 普通任务提醒
- 循环计划每日提醒
- 使用系统本地通知
- 不需要服务器，不需要登录

### 5. 轻量统计

- 第一版只做四项：

  - 今日完成进度
  - 当前周期进度
  - 连续打卡天数
  - 简单热力图

  后续可扩展，但第一版不做复杂统计

### 6. 未完成原因

- 今日任务没有完成时，用户可以追加说明原因
- 原因不强制填写
- 日后可在任务详情、某天详情、统计页中查看
- 快捷原因：
  - 没时间
  - 身体不适
  - 临时有事
  - 忘记
  - 任务太难
  - 天气原因
  - 其他
- 支持自由文本

### 7. 数据管理：导入、导出、恢复

- 数据只保存在本机
- 导出备份：全部数据导出为 JSON 文件
- 导入恢复：选择 JSON 文件恢复
- 导入模式：
  - 覆盖现有数据
  - 合并到现有数据
- 清空数据
- 可选应用锁：PIN / 指纹 / 面容

## 七、关键规则

- 循环计划按“第几天”算，不按星期几算。
- 今日任务 = 今天的普通任务 + 启用循环计划中今天的任务。
- 勾选完成只影响当天实例，不修改循环模板。
- 修改循环任务时，默认只改今天；需要时选“以后所有”。
- 未完成原因只保存在本机，导出 JSON 时一并导出。
- 连续打卡定义：
  - 当天有任务且全部完成，算打卡 1 天。
  - 无任务日跳过，不计入，也不打断。
  - 未完成或跳过，不算打卡。
- 简单热力图：
  - 最近 90 天或最近一年。
  - 每天一个格子。
  - 颜色越深，完成率越高。
  - 点击某天进入“某天详情”。
- 导入导出用 JSON，文件里带版本号。
- 所有数据只在本机，不上传。
- 【新增】结束日期当天仍然执行。
- 【新增】结束日期次日不再生成新任务实例。
- 【新增】如果结束日不是周期最后一天，允许最后一轮截断。
- 【新增】可选“完整周期结束后停止”，系统自动找到该日期前最后一个完整周期。
- 【新增】已结束计划自动归档，不再提醒，历史记录保留。
- 【新增】暂停可恢复，结束不可继续，可复制成新计划。
- 【新增】修改结束日期后，未来实例重新生成，历史记录不变。

## 八、JSON 备份结构示例

### 1. 主要数据

| 数据     | 说明                 |
| :------- | :------------------- |
| Task     | 普通任务             |
| Cycle    | 循环计划模板         |
| CycleDay | 周期内第几天         |
| Record   | 某一天的任务实例记录 |
| Settings | 设置                 |

### 2. Record 字段建议

| 字段            | 说明                        |
| :-------------- | :-------------------------- |
| id              | 唯一 ID                     |
| taskId          | 对应任务模板                |
| cycleId         | 属于哪个循环计划，可为空    |
| cycleDayIndex   | 第几天，可为空              |
| date            | 哪一天的任务                |
| status          | 完成 / 未完成 / 跳过 / 待办 |
| completedAt     | 完成时间                    |
| reason          | 未完成原因                  |
| reasonUpdatedAt | 原因更新时间                |
| rescheduledFrom | 从哪天顺延而来              |

### 3. 状态建议

- `pending`：待办
- `completed`：完成
- `skipped`：跳过
- `missed`：未完成

### 4. 【新增】Cycle 字段建议

| 字段     | 说明                           |
| :------- | :----------------------------- |
| endType  | never / afterCount / untilDate |
| endDate  | 结束日期，可为空               |
| endCount | 循环次数，可为空               |
| status   | active / paused / ended        |
| endedAt  | 实际结束时间                   |

### 5.【新增】修改作用域建议（第二版可加）

| 字段         | 说明                             |
| :----------- | :------------------------------- |
| scope        | once / fromNowUntil / fromNowAll |
| scopeEndDate | 本次修改截止日期，可为空         |

### 6. JSON 备份结构示例

json

```
{
  "version": 1,
  "exportedAt": "2026-09-11T10:00:00+08:00",
  "tasks": [],
  "cycles": [],
  "records": [
    {
      "id": "record_uuid",
      "taskId": "task_uuid",
      "cycleId": "cycle_uuid",
      "cycleDayIndex": 3,
      "date": "2026-09-11",
      "status": "missed",
      "completedAt": null,
      "reason": "加班，没时间",
      "reasonUpdatedAt": "2026-09-11T22:30:00+08:00",
      "rescheduledFrom": null
    }
  ],
  "settings": {}
}
```

## 十一、一句话总结

**4 个 Tab：今日、任务、计划、设置。**
**2 个核心编辑页：任务编辑、计划编辑。**
**1 个数据页：导出 / 导入恢复。**
**1 个轻量统计页：今日进度、周期进度、连续打卡、简单热力图。**

所有数据本地保存，不上传，导出 JSON 时包含未完成原因。
